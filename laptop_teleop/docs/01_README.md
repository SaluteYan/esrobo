功能变化直接更新对应现行文档，再在 08 追加日期条目。不要为每次调参、故障分析或验收重新建一个文档；同一天可按主题分小节。修改日志中的历史参数和测试数量不代表当前配置或当前硬件状态。若必须增加新的长期主题，先检查能否合并，并保持编号连续、同步修正仓库内引用。
